Odentia 🦷
A modern digital space for dentistry, learning, and exploration.
Odentia is a web project developed under Aevura Labs, created to bring dental knowledge, educational resources, and interactive experiences together in a simple and modern interface.
✨ Features
🦷 Modern dental-focused interface
📚 Educational resources and learning content
🔎 Organized information and resources
💻 Responsive design for different screen sizes
🎨 Clean and modern visual design
🚀 Built with web technologies and designed for future expansion
🛠️ Technologies
Currently, Odentia is built using:
HTML5
CSS3
JavaScript
More technologies and features may be introduced as the project evolves.
